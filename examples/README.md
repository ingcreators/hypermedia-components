# Examples

Framework-specific usage examples. Each subdirectory is a minimal runnable example that imports `@hypermedia-components/core`:

```text
plain-html/      Static HTML + CDN <link>/<script>
htmx/            Plain HTML + htmx
java-thymeleaf/  Thymeleaf templates
python-django/   Django templates
rails/           ERB templates
go/              html/template
```

Examples are illustrative; they are not published packages.
