---
title: ビヘイビア
description: すべての installXxx() ビヘイビア — 何を担い、ゼロ設定バンドルが自動インストールするかの一覧。
---

キットは 44 個の小さなビヘイビアを出荷しています。すべて冪等で
アンインストーラを返し、`installChart()` ただ 1 つの例外を除いて、
ゼロ設定の `@hypermedia-components/core/behaviors` エントリが
**自動インストール**します(htmx でスワップされた内容も拾います)。
個別 import が必要になるのは、選択的にバンドルするときだけです。

```js
// Everything at once (what the CDN bundle does):
import '@hypermedia-components/core/behaviors';

// Or pick and choose:
import { installTabs, installToast } from '@hypermedia-components/core';
installTabs();
installToast();
```

## アクションとフォーム

| ビヘイビア | 担当 | 自動 |
| --- | --- | --- |
| `installValidation()` | [フィールド](/hypermedia-components/ja/components/field/)のネイティブ検証の配線(blur/submit 検証、メッセージスロット)。 | ✓ |
| `installFieldErrors()` | サーバー駆動のインラインエラー — [field-errors レシピ](/hypermedia-components/ja/recipes/field-errors/)の 422 フラグメント契約。 | ✓ |
| `installCombobox()` | [コンボボックス](/hypermedia-components/ja/components/combobox/)のキーボード・フィルタ・ARIA。 | ✓ |
| `installMulticombobox()` | [マルチコンボボックス](/hypermedia-components/ja/components/multicombobox/)のタグ・キーボード・ARIA。 | ✓ |
| `installInputOtp()` | [Input OTP](/hypermedia-components/ja/components/inputotp/) のスロット単位編集。 | ✓ |
| `installPasswordToggle()` | [インプットグループ](/hypermedia-components/ja/components/input-group/)のパスワード表示切替。 | ✓ |
| `installSlider()` | [スライダー](/hypermedia-components/ja/components/slider/)の塗り + 値出力の同期。 | ✓ |
| `installRange()` | [レンジ](/hypermedia-components/ja/components/range/)のデュアルサムのクランプ + 塗り。 | ✓ |
| `installCalendar()` | [カレンダー](/hypermedia-components/ja/components/calendar/)のグリッド・キーボード・選択。 | ✓ |
| `installDropzone()` | [ドロップゾーン](/hypermedia-components/ja/components/dropzone/)のドラッグオーバー状態 + ファイル一覧。 | ✓ |
| `installUploadProgress()` | htmx のアップロードイベントで `<progress>` を駆動 — [file-upload レシピ](/hypermedia-components/ja/recipes/file-upload/)。 | ✓ |
| `installCodeEditor()` | 編集可能な[コード](/hypermedia-components/ja/components/code/)フィールド: ガター、ライブハイライト(`data-lang`)。 | ✓ |
