リファレンスページは、`@hypermedia-components/core` が出荷する名前と
契約の正式な一覧です。

- [マシンマニフェスト](/hypermedia-components/ja/reference/manifest/) — `manifest.json` + `custom-elements.json`: ツールとエージェント向けの構造化 JSON。
- [ビヘイビア](/hypermedia-components/ja/reference/behaviors/) — すべての `installXxx()` を一覧で: 何を担い、ゼロ設定バンドルが自動インストールするか。
- [カスタム要素](/hypermedia-components/ja/reference/custom-elements/) — 任意のマクロ要素(`<hc-confirm-action>`、`<hc-live-search>`)と、それらが従うアップグレード契約。
- [バンドルサイズ](/hypermedia-components/ja/reference/size/) — パッケージのエントリポイントとその gzip サイズ。
- [バージョニング](/hypermedia-components/ja/reference/versioning/) — 「マークアップはワイヤ契約」ポリシー: 何が公開 API で、バージョンアップで何が変わりうるか。
- [パフォーマンス](/hypermedia-components/ja/reference/performance/) — デプロイ済み docs への週次 Lighthouse バジェット。
