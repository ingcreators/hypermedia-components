title: レシピ
description: htmx フレンドリーなパターン集 — 確認アクション、ライブ検索、リモートダイアログ、インライン編集、レイジーパネル、トーストなど。
---

各レシピは、短縮形・展開後の HTML・任意のマクロ・サーバレスポンス契約を
ドキュメント化しています。**必要なもの**列に記載のあるレシピは
[`@hypermedia-components/core`](/hypermedia-components/ja/start/installation/#ビヘイビア)の
`installX()` を必要とします。それ以外(「—」)は純粋な htmx 属性だけです。

任意のレシピのスキャフォールドは
`npx @hypermedia-components/cli add <name>` で取得できます。コピーは
`npx @hypermedia-components/cli validate` で契約に対して機械検証できます。

各レシピページには**ライブデモ**もあります。ほぼすべてのデモは、
このサイトの Worker が `api/recipes/<name>/` 配下で実装する
各レシピのサーバ応答契約に対して、実際の htmx リクエストを送ります
(例外: [コピー](/hypermedia-components/ja/recipes/copy/)と
[条件付きフィールド](/hypermedia-components/ja/recipes/conditional-fields/)は
クライアントのみ、[ストリーミング応答](/hypermedia-components/ja/recipes/streaming-response/)は
chat-messages のエンドポイントを共有)。

## アクションとフォーム

| レシピ | やりたいこと | 必要なもの |
| --- | --- | --- |
| [ミューテーションフォーム](/hypermedia-components/ja/recipes/mutating-form/) | インライン 4xx エラー・成功時リダイレクト・二重送信ガードつきでフォームを送信する | `installFieldErrors()` |
| [フィールドエラー](/hypermedia-components/ja/recipes/field-errors/) | サーバが送るバリデーションエラーフラグメントを、名前の一致するフィールドへ振り分ける | `installFieldErrors()` |
| [マルチステップフォーム](/hypermedia-components/ja/recipes/multi-step-form/) | ウィザードを作る — ステップとドラフトはサーバが所有し、ステップ全体をスワップ | — |
| [確認アクション](/hypermedia-components/ja/recipes/confirm-action/) | 破壊的リクエストを確認ダイアログでガードする | `installConfirm()` |
| [削除の取り消し](/hypermedia-components/ja/recipes/undo-delete/) | 即座に削除する(楽観的削除)— 猶予期間内ならトーストの Undo で行を復元 | `installToast()` |
| [リクエストアクション](/hypermedia-components/ja/recipes/request-action/) | ビジー状態つきのボタンから htmx リクエストを発行する | — |
| [インライン編集](/hypermedia-components/ja/recipes/inline-edit/) | 値を表示モードと編集モードの間でその場でスワップする(クリックして編集) | — |
| [ファイルアップロード](/hypermedia-components/ja/recipes/file-upload/) | ライブ進捗バーと out-of-band フォームリセットつきでマルチパートアップロードする | `installUploadProgress()` |
| [データグリッド一括操作](/hypermedia-components/ja/recipes/datagrid-bulk-actions/) | チェックボックスで行を選択し、1 つのアクションを全行に POST する | `installDatagridActions()` |
| [トランスファー](/hypermedia-components/ja/recipes/transfer/) | デュアルリストボックスの割り当て / 解除をサーバ往復で行う — フォーム全体のスワップ、カスタム JS ゼロ | — |
| [カスケードセレクト](/hypermedia-components/ja/recipes/cascading-select/) | 階層選択を連鎖する(依存)select で行う — change のたびに次のレベルを読み込み | — |
| [クリップボードにコピー](/hypermedia-components/ja/recipes/copy/) | 読み取り専用の値(URL、トークン、スニペット)をクリップボードへコピーする | `installCopy()` |
| [条件付きフィールド](/hypermedia-components/ja/recipes/conditional-fields/) | 選択中のモードが読まないフィールドを、往復なしで宣言的に隠す | `installShowWhen()` |
| [並べ替えリスト](/hypermedia-components/ja/recipes/sortable/) | サーバが順序を所有するリストをポインタ/キーボードで並べ替え、リクエスト 1 本で永続化する | `installSortable()` |

| レシピ | やりたいこと | 必要なもの |
| --- | --- | --- |
| [チャットメッセージ](/hypermedia-components/ja/recipes/chat-messages/) | コンポーザーの 1 POST でチャットのやり取り(ユーザーメッセージ + aria-busy のアシスタントプレースホルダー)を追記。422 経路はトランスクリプトを汚しません | `installChatScroll()` |
