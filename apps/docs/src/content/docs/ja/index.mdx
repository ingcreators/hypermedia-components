## 標準 HTML を、組み合わせる

すべてのコンポーネントは、ネイティブ要素に載せたセマンティックなクラスです。いくつかを実際に動く形で紹介します — テーマ対応で、素の HTML マークアップだけでできています。ヘッダーのカラー / 密度 / ダークモード切り替えを試してみてください。
