title: 基礎
description: すべての Hypermedia Components に共通する概念 — 命名規則、トークン、htmx 統合。
---

ライブラリ全体に共通する概念です。初めての方は、まず**命名規則**と
**トークン**から — すべてのコンポーネントページが前提とする語彙を
説明しています。

- [命名規則](/hypermedia-components/ja/fundamentals/naming/) — クラス、data 属性、カスタムプロパティ、イベント。
- [トークン](/hypermedia-components/ja/fundamentals/tokens/) — あらゆる `--hc-*` 値の背後にある DTCG トークンレイヤー。
- [レイアウトユーティリティ](/hypermedia-components/ja/fundamentals/layout/) — 本質的にレスポンシブなレイアウトプリミティブ。
- [レスポンシブデザイン](/hypermedia-components/ja/fundamentals/responsive/) — コンテナファースト戦略と各ツールの使いどころ。
- [国際化(i18n)](/hypermedia-components/ja/fundamentals/i18n/) — ビヘイビアが注入する文字列を 1 つのメッセージカタログで翻訳。
- [アクセシビリティ](/hypermedia-components/ja/fundamentals/accessibility/) — CSS システムカラーによる Forced Colors / Windows ハイコントラスト対応。

インタラクティブなコンポーネントは小さな JS *ビヘイビア*に依存します —
インストール方法と冪等性の理由は
[インストール → ビヘイビア](/hypermedia-components/ja/start/installation/#ビヘイビア)を
参照してください。
