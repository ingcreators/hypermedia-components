Hypermedia Components は、サーバレンダリングおよびハイパーメディアアプリケーションのためのセマンティック UI コンポーネントシステムです。

提供するもの:

- セマンティックな CSS コンポーネント(`hc-button`、`hc-field`、`hc-card`、…)
- DTCG [トークン](/hypermedia-components/ja/tokens/)ソースと、そこから生成される CSS 変数
- htmx 対応の[レシピ](/hypermedia-components/ja/recipes/)
- 小さな[ビヘイビアヘルパー](/hypermedia-components/ja/start/installation/#ビヘイビア)
- 任意で使える [Light DOM マクロ](/hypermedia-components/ja/reference/custom-elements/)
- コピーして使える展開済み HTML
- ドキュメント化されたサーバレスポンス契約

2. [クイックスタート](/hypermedia-components/ja/start/quick-start/) — 最初のコンポーネントを一歩ずつ組み立てます。
