Hypermedia Components は、サーバレンダリングおよびハイパーメディアアプリケーションのためのセマンティック UI コンポーネントシステムです。

提供するもの:

- セマンティックな CSS コンポーネント(`hc-button`、`hc-field`、`hc-card`、…)
- DTCG [トークン](/hypermedia-components/ja/fundamentals/tokens/)ソースと、そこから生成される CSS 変数
- htmx 対応の[レシピ](/hypermedia-components/ja/recipes/)
- 小さな[ビヘイビアヘルパー](/hypermedia-components/ja/start/installation/#ビヘイビア)
- 任意で使える [Light DOM マクロ](/hypermedia-components/ja/reference/custom-elements/) —
  各マクロは展開後の HTML をドキュメント化しており、コピーして使えるため、マクロにロックインされることはありません
- ドキュメント化されたサーバレスポンス契約

## 次のステップ

1. [インストール](/hypermedia-components/ja/start/installation/) — アセットの読み込み(CDN、npm、または静的ファイル)。
2. [クイックスタート](/hypermedia-components/ja/start/quick-start/) — 最初のコンポーネントを一歩ずつ組み立てます。
3. [設計思想](/hypermedia-components/ja/start/philosophy/) — このキットを支える原則。
4. [キッチンシンク](/hypermedia-components/ja/kitchen-sink/) — 全コンポーネントを 1 ページでライブ表示。キットを評価する最速の方法です。
5. [インテグレーション](/hypermedia-components/ja/integrations/) — Django、Rails、Go、Razor などのサーバスタックへの組み込み方。
