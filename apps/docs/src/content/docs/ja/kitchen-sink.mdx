---
title: キッチンシンク
description: Hypermedia Components の全コンポーネントを 1 ページに — ひと目で見渡せるライブギャラリー。各コンポーネントの完全なドキュメントへのリンクつき。
---

すべてのコンポーネントを、ライブで、1 ページに — **コンポーネント**の
サイドバーと同じグルーピングです。ライブラリ全体をひと目で見渡す、
テーマの健全性チェック(ヘッダーのカラー / 密度 / ダークの切り替えを
試してください)、見出しのリンクからコンポーネントの完全なドキュメント
へ飛ぶ、といった用途に使ってください。

:::note
インタラクティブなコンポーネントはここで本物のビヘイビアを動かして
います(docs サイトは `@hypermedia-components/core/behaviors` を
読み込みます)。メニューを開く、スプリッターをドラッグする、OTP
フィールドに入力する — すべて動きます。
:::
