## The markup is the contract

What you write is what ships — a semantic class on a native element,
state in attributes, no wrapper runtime. The Code tab below *is* the
wire format a server (or template engine, or code generator) emits:

## HTML over the wire

The server answers with fragments, htmx swaps them in, and the
components just work — no JSON, no client state. Type below: a
debounced request hits this site's
<a href="/hypermedia-components/recipes/live-search/">demo API</a> and
the results fragment swaps back.

</section>

Every one of the <a href="/hypermedia-components/recipes/"><Count of="recipes" /> recipes</a>
works this way — each page documents the server contract and runs it
live against this site's Worker. The
<a href="/hypermedia-components/templates/">page templates</a> compose
them into full screens.
