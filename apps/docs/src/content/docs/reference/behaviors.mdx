title: Behaviors
description: Every installXxx() behavior — what it powers and whether the zero-config bundle auto-installs it.
---

The kit ships 44 small behaviors. All of them are idempotent, return an
uninstaller, and — with the single exception of `installChart()` — are
**auto-installed** by the zero-config
`@hypermedia-components/core/behaviors` entry, which also picks up
content swapped in by htmx. Import them individually only when you
bundle selectively.

```js
// Everything at once (what the CDN bundle does):
import '@hypermedia-components/core/behaviors';

// Or pick and choose:
import { installTabs, installToast } from '@hypermedia-components/core';
installTabs();
installToast();
```

## Actions & forms

| Behavior | Powers | Auto-init |
| --- | --- | --- |
| `installValidation()` | Native-validation wiring for [fields](/hypermedia-components/components/field/) (blur/submit validation, message slots). | ✓ |
| `installFieldErrors()` | Server-driven inline errors — the [field-errors recipe](/hypermedia-components/recipes/field-errors/)'s 422 fragment contract. | ✓ |
| `installCombobox()` | [Combobox](/hypermedia-components/components/combobox/) keyboard, filtering, ARIA. | ✓ |
| `installMulticombobox()` | [Multicombobox](/hypermedia-components/components/multicombobox/) tags, keyboard, ARIA. | ✓ |
| `installInputOtp()` | [Input OTP](/hypermedia-components/components/inputotp/) per-slot editing. | ✓ |
| `installPasswordToggle()` | The [input-group](/hypermedia-components/components/input-group/) password reveal. | ✓ |
| `installSlider()` | [Slider](/hypermedia-components/components/slider/) fill + value output sync. | ✓ |
| `installRange()` | [Range](/hypermedia-components/components/range/) dual-thumb clamping + fill. | ✓ |
| `installCalendar()` | [Calendar](/hypermedia-components/components/calendar/) grid, keyboard, selection. | ✓ |
| `installDropzone()` | [Dropzone](/hypermedia-components/components/dropzone/) drag-over state + file list. | ✓ |
| `installUploadProgress()` | Driving a `<progress>` from htmx upload events — the [file-upload recipe](/hypermedia-components/recipes/file-upload/). | ✓ |
| `installCodeEditor()` | The editable [code](/hypermedia-components/components/code/) field: gutter, live highlight (`data-lang`). | ✓ |
