Concepts that apply across the whole library. New here? Start with
**Naming** and **Tokens** — they explain the vocabulary every component
page assumes.

- [Naming](/hypermedia-components/fundamentals/naming/) — classes, data attributes, custom properties, events.
- [Tokens](/hypermedia-components/fundamentals/tokens/) — the DTCG token layers behind every `--hc-*` value.
- [Layout utilities](/hypermedia-components/fundamentals/layout/) — intrinsically responsive layout primitives.
- [Responsive design](/hypermedia-components/fundamentals/responsive/) — the container-first strategy and where each tool fits.
- [Internationalization (i18n)](/hypermedia-components/fundamentals/i18n/) — translate the strings behaviors inject, with one message catalog.
- [Accessibility](/hypermedia-components/fundamentals/accessibility/) — Forced Colors / Windows High Contrast support via CSS system colours.

Interactive components rely on small JS *behaviors* — see
[Installation → Behaviors](/hypermedia-components/start/installation/#behaviors)
for how they install and why they are idempotent.
