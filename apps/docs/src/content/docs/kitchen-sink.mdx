Every component, live, on one page. Use it to scan the whole library
at a glance, sanity-check theming (try the colour / density / dark
switchers in the header), or jump to a component's full docs via its
heading link.

:::note
Interactive components run their real behaviors here (the docs site
loads `@hypermedia-components/core/behaviors`). Open the menus, drag the
splitter, type in the OTP field — it all works.
:::
