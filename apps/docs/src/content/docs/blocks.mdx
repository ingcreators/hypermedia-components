description: Realistic UI sections built by composing Hypermedia Components — settings panels, data tables, sign-in cards, and a full app shell.

The [Components](/hypermedia-components/components/) pages show each part on
its own; **blocks** show them working *together*. Each one below is plain
HTML using the documented classes — the same components, composed into the
kind of section you actually ship. Interactive bits (menus, toasts, …)
install the same way as everywhere else (see
[Installation → Behaviors](/hypermedia-components/start/installation/#behaviors)).
