The data grid is the largest subsystem in the kit: the
[`hc-datagrid`](/hypermedia-components/components/datagrid/) component,
the [Data grid page](/hypermedia-components/templates/data-grid-page/)
template, and thirteen recipes that each add one operation a business
grid is used for. Each of those pages documents its own markup and
server contract in full — this page is the map: what exists, what
depends on what, and the order a real grid grows in.

## Start here

1. **[The component](/hypermedia-components/components/datagrid/)** —
   the markup: sticky multi-level headers, frozen columns, numeric
   columns, states, and `installDatagrid()`'s keyboard model. Render
   your data with it before adding any operation.
2. **[The page template](/hypermedia-components/templates/data-grid-page/)**
   — the layout the grid sits in: an app shell where *only the grid
   scrolls*, the filter panel, and the chrome placement rules. Copy it
   rather than rediscovering its height rule.
3. **Add operations as recipes** — each stage below is independent;
   take only what the screen needs.

## Stage 2 — operate (the read path)

Every read operation is the same wire: a form GETs the grid URL with
namespaced params, and the server re-renders the grid (and the
control's own state) from them.

| You need to… | Recipe |
| --- | --- |
| page from the server | [Datagrid pagination](/hypermedia-components/recipes/datagrid-pager/) |
| an editable, ordered sort set | [Datagrid sort](/hypermedia-components/recipes/datagrid-sort/) |
| per-column filters | [Datagrid filter](/hypermedia-components/recipes/datagrid-filter/) |
| per-user column choice | [Datagrid columns](/hypermedia-components/recipes/datagrid-columns/) |
| remembered widths and order | [Datagrid prefs](/hypermedia-components/recipes/datagrid-prefs/) |
| open a row's record and come back to the same list | [Row detail](/hypermedia-components/recipes/row-detail/) |
| name the current filters and recall them as links | [Saved views](/hypermedia-components/recipes/saved-views/) |
| bound what one search may return | [Result cap](/hypermedia-components/recipes/result-cap/) |

## Stage 3 — edit (the write path)

Inline editing's markup and keyboard model live on the
[component page](/hypermedia-components/components/datagrid/#inline-editing);
the two recipes are its error wires — each row is its own record
`tbody`, so both re-render one record atomically.

| You need to… | Recipe |
| --- | --- |
| reject a bad commit — 422 re-renders the record with the marked cell | [Datagrid edit errors](/hypermedia-components/recipes/datagrid-edit-errors/) |
| optimistic locking per row — a stale save 409s into a conflict row | [Datagrid edit conflict](/hypermedia-components/recipes/datagrid-edit-conflict/) |

## Stage 4 — bulk &amp; scale

| You need to… | Recipe |
| --- | --- |
